# KAGARIHI 簿記Bot

Discordで複式簿記を管理するBotです。

## セットアップ

```bash
pip install -r requirements.txt
cp .env.example .env
# .env を編集して DISCORD_TOKEN を設定
python main.py
```

## スラッシュコマンド一覧

| コマンド | 説明 |
|---|---|
| `/仕訳` | 仕訳を記録（借方・貸方・金額・摘要） |
| `/仕訳帳` | 最近の仕訳を一覧表示 |
| `/仕訳削除` | 指定IDの仕訳を削除 |
| `/試算表` | 残高試算表を表示 |
| `/損益計算書` | 損益計算書（PL）を表示 |
| `/貸借対照表` | 貸借対照表（BS）を表示 |
| `/勘定科目一覧` | 登録済み勘定科目を一覧表示 |
| `/勘定科目追加` | 新しい勘定科目を追加 |

## デフォルト勘定科目

- **資産**: 現金、普通預金、売掛金
- **負債**: 買掛金、未払金
- **資本**: 資本金、繰越利益剰余金
- **収益**: 売上、受取利息
- **費用**: 仕入、給料、旅費交通費、通信費、消耗品費

## 使用例

```
/仕訳 借方:現金 貸方:売上 金額:100000 摘要:商品販売
/仕訳 借方:消耗品費 貸方:現金 金額:5000 摘要:文具購入
/仕訳帳 件数:20
/試算表
/損益計算書
/貸借対照表
```
